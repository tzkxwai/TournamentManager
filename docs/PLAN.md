## О проекте

TournamentManager — приложение для проведения турниров и ведения рейтинга игроков.

Основные задачи: создание турниров, добавление участников, автоматическое формирование турнирной сетки, проведение матчей, запись результатов, определение победителей и хранение информации в базе данных.

В проекте реализован пересчёт рейтинга игроков после завершения матчей. Возможность дальнейшего развития рейтинговой системы по алгоритму Эло сохраняется.

В `TournamentService` реализованы:

- отображение турнирной сетки;
- запись результатов матчей;
- отображение чемпиона турнира.

Веб-приложение взаимодействует с сервисами через HTTP API.

## Структура программы

- **PlayerService** — работа с игроками и их рейтингами.
- **TournamentService** — создание турниров, участники, турнирная сетка, матчи, победители и завершение турниров.
- **TournamentWeb** — веб-интерфейс для взаимодействия с системой через API.
- **PlayerService.Tests** и **TournamentService.Tests** — автоматические тесты сервисов и ключевой логики.

## Нереализованные и отложенные задачи

- Отдельный `MatchService` не выделен.
- Дополнительное развитие рейтинговой системы Эло.
- Полноценная авторизация и разделение пользователей по ролям.
- Дополнительная проверка инструкции запуска на чистой машине.

## Возможные сложности и способы решения

- **Взаимодействие сервисов:** проверять адреса API и доступность сервисов, обрабатывать ошибки HTTP-запросов.
- **База данных:** проверять регистрацию `DbContext`, строку подключения и применение миграций.
- **Занятые порты:** определять процесс, использующий порт, и завершать только соответствующий процесс.
- **Блокировка файлов при сборке:** останавливать запущенное приложение перед повторной сборкой.
- **Турнирная сетка:** проверять сценарии с разным количеством участников и корректность определения победителя.
