## О проекте

TournamentManager — приложение для проведения турниров и ведения рейтинга игроков.

Основные задачи проекта:
- создание турниров;
- добавление участников;
- автоматическое формирование турнирной сетки;
- проведение матчей;
- запись результатов;
- определение победителей;
- хранение информации в базе данных.

В дальнейшем планируется реализовать автоматический пересчёт рейтинга игроков по системе Эло.

## Структура программы

На текущем этапе решение состоит из двух основных сервисов и двух тестовых проектов.

### PlayerService

Предназначен для работы с игроками.

### TournamentService

Отвечает за:
- создание турниров;
- добавление участников;
- формирование турнирной сетки;
- проведение матчей;
- определение победителей;
- завершение турниров.

### TournamentService.Tests

Содержит автоматические тесты генерации турнирной сетки и работы с базой данных.

### PlayerService.Tests

Содержит автоматические тесты PlayerService.

В дальнейшем планируется выделить работу с матчами и рейтингами в отдельный сервис.

## Возможные сложности

Во время разработки могут возникать проблемы с:
- взаимодействием между сервисами;
