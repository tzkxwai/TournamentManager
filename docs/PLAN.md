## О проекте

Я планирую сделать приложение для проведения турниров и
ведения рейтинга игроков. В нём можно будет создавать
турниры, добавлять участников, проводить матчи и
записывать их результаты.

После завершения матчей программа будет автоматически
определять победителей и пересчитывать рейтинг игроков
по системе Эло.

## Структура программы

Программа будет состоять из трёх сервисов.

PlayerService отвечает за пользователей, игроков и
авторизацию.

TournamentService отвечает за создание турниров,
добавление участников и составление турнирной сетки.

MatchService отвечает за результаты матчей и
расчёт рейтинга игроков.

У каждого сервиса будет своя база данных.

Для работы с программой будет сделан веб-интерфейс.
