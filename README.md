
# TournamentManager

TournamentManager — приложение для организации турниров
и ведения рейтинга игроков.

С помощью программы можно будет создавать турниры,
добавлять участников, проводить матчи и сохранять
их результаты.

После завершения матчей система будет автоматически
определять победителей и изменять рейтинг игроков
по системе Эло.

## Используемые технологии

C# и ASP.NET Core — для создания приложения и сервисов.

Entity Framework Core и SQLite — для работы с базами данных.

HTML и CSS — для веб-интерфейса.

Docker — для запуска всех сервисов.

xUnit — для автоматического тестирования.

## Структура проекта

PlayerService — работа с пользователями и игроками.

TournamentService — создание турниров и турнирных сеток.

MatchService — проведение матчей и расчёт рейтинга Эло.

TournamentWeb — веб-интерфейс приложения.
